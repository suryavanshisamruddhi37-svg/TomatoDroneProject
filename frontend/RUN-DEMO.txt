CROPCare AI - Full Frontend Demo

1. Extract this ZIP.
2. Open frontend/login.html in Chrome.
3. Click Create Account and register a demo farmer.
4. You will enter the dashboard automatically.
5. Test Dashboard, Upload & Detect, Prediction History, Tomato Diseases,
   Quality Guide, Profile, Logout, and the landing page (index.html).

DEMO MODE:
The frontend is configured with DEMO_MODE = true in frontend/js/api.js.
No Flask/FastAPI backend is required to test the UI.
Registration, login, dashboard statistics, prediction history and prediction
results use browser localStorage/sessionStorage.

Upload & Detect:
You can select or drag an image. The demo returns a simulated Early Blight
result so you can verify the complete frontend flow. Your actual ML model
will still need the backend/API for real disease detection.

When your backend is ready:
Change DEMO_MODE = false in frontend/js/api.js and set API_BASE_URL to your
backend API address.
